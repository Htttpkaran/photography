# Photography Website

A React + Vite photography portfolio website with sections for hero, services, gallery, founder, reviews, and contact.

## Setup

### Prerequisites
- Node.js (LTS recommended)
- npm

### Install dependencies
```bash
npm install
```

### Run in development
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

### Lint
```bash
npm run lint
```
